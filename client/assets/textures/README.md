# 📦 Текстуры

Сюда складываем текстуры для игры. Dev-сервер раздаёт всё, что лежит внутри `client/`,
так что файлы сразу доступны по URL вида `/assets/textures/ground/grass_diffuse.jpg`.

> **3D-модели (props) сюда не кладём** — весь пропс (ящики, кактусы, оружие и т.д.)
> генерируется процедурно в коде. Эта папка — только для текстур поверхностей.

## Папки

| Папка | Что класть |
|-------|------------|
| `ground/`   | земля: трава, песок, грунт (обязательно **бесшовные**) |
| `buildings/`| бетон, штукатурка, старое дерево, профнастил/металл контейнеров |
| `sky/`      | скайбокс / панорама (по желанию) |

## Формат и размер

- **Форматы:** `.jpg`, `.png`, `.webp` (лучше JPG/WebP — меньше вес)
- **Разрешение:** степени двойки — 512, 1024 или 2048 (1024 — золотая середина)
- **Бесшовность (tileable):** для земли и стен обязательно, иначе будут видны швы

## Именование (PBR-набор)

Для одного материала кладём файлы с суффиксами:

```
grass_diffuse.jpg     — базовый цвет (обязательно)
grass_normal.jpg      — карта нормалей (желательно, для Ultra)
grass_roughness.jpg   — шероховатость (по желанию)
```

Если есть только один файл (просто цветная картинка) — называем `имя_diffuse.jpg`,
движок сам подставит остальное по умолчанию.

## Минимальный набор, который нужен прямо сейчас

1. **Трава** (бесшовная) — для травянистой карты и земли
2. **Песок** (бесшовный) — для Desert 2
3. **Бетон/штукатурка** — стены многоэтажек
4. **Старое дерево** — старый дом-укрытие
5. **Металл (профнастил)** — контейнеры
