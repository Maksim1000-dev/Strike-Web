# Strike-Web

Онлайн-шутер в браузере в стиле Counter-Strike (CS 2 / CS:GO) на **Three.js**.
Подробный план проекта — в [PLAN.md](PLAN.md).

## Запуск

```bash
npm install
npm run dev
```

Сервер слушает `0.0.0.0:3000` и раздаёт статику из `client/`, а Three.js — из `node_modules`.

## Управление

- **WASD** — движение
- **Мышь** — обзор (клик захватывает курсор; если Pointer Lock недоступен — зажми и веди мышью)
- **Space** — прыжок
- **Shift** — бег
- **M** / кнопка **⚙** — настройки
- **Esc** — выход из захвата курсора

## Настройки графики

Три пресета качества (переключаются в меню и применяются на лету):

| Пресет | Что включено |
|--------|--------------|
| **Низкое** | процедурные текстуры, без теней/травы/bloom, pixel ratio 1 |
| **Среднее** | детальные процедурные текстуры, тени, статичная трава |
| **Ультра** | bloom (пост-обработка), качающиеся трава и кактусы, текстуры в высоком разрешении |

Уровень определяется автоматически по железу (deviceMemory / ядра / мобильность).
> Примечание: «реальные текстуры из интернета» пока заменены процедурными (в окружении разработки внешние CDN закрыты) — загрузка PBR-текстур добавится позже.

## Структура

```
client/
  index.html            — входная точка
  css/style.css         — стили (HUD, меню настроек)
  js/
    main.js             — сборка сцены, запуск цикла, FPS
    config.js           — пресеты графики (Low/Medium/Ultra), авто-определение
    core/
      engine.js         — рендерер, сцена, камера, пост-обработка, цикл
      input.js          — клавиатура
      player.js         — контроллер от первого лица (физика, коллизии)
    graphics/
      textures.js       — процедурные текстуры (value-noise / fBm)
      postfx.js         — пост-обработка (bloom + tone mapping)
    world/
      sandbox.js        — песочница: земля, ящики, свет, небо
      grass.js          — поле травы (InstancedMesh, шейдер ветра)
      cacti.js          — процедурные кактусы (качаются в Ultra)
    ui/
      hud.js            — HUD, оверлей старта
      settings.js       — панель настроек графики
    utils/random.js     — детерминированный PRNG
server/
  dev-server.js         — dev-сервер статики (без внешних зависимостей)
```
